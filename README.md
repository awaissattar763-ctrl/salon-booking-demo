# Glow Studio — Salon Booking (Concept Demo)

Live: https://awaissattar763-ctrl.github.io/salon-booking-demo/

**This is a concept demo, not a real salon.** "Glow Studio" is fictional. Services, prices, time slots and availability are simulated. No real bookings are made, no reviews are shown.

## What it demonstrates
- Service menu with realistic Pakistani salon prices (Rs.) and durations
- Next-7-days date picker + time-slot selection (booked slots simulated, past slots disabled for today)
- Booking form (name + phone, validated)
- Booking summary + **WhatsApp confirm button** — opens wa.me with the booking details pre-filled (in production this points to the salon's own WhatsApp number)

## Tech
Single static `index.html` — no build step, no dependencies. Deployed via GitHub Pages.
